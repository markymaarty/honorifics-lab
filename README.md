# Honorifics Lab

Free interactive web app to learn **Korean** and **Japanese** honorifics and politeness systems.

## Features
- Korean: Speech levels (존댓말 / 반말), -시- honorific, special vocabulary
- Japanese: Teineigo, Sonkeigo, Kenjōgo
- Beginner + Intermediate levels with lessons and quizzes
- Progress saved in browser (localStorage)
- Completely free, no accounts, no subscriptions

## How to use
Open `index.html` in any modern browser, or deploy to Vercel/Netlify.
